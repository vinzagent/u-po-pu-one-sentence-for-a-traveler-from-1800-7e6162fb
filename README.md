One sentence (198 characters) explaining the modern internet to a time traveler from 1800, built only from things a person from 1800 already knows — a road, a library, a post office, a letter, ink, a book:

> Picture a single road joining every great library and post office on earth to your door, where any letter you post arrives before your ink dries and any book you ask for opens in your hands at once.

`main.py` validates the sentence (1–200 characters, exactly one sentence, one line) and writes it to `/output/entry.txt`, then prints it to stdout.

## Run it

```sh
python3 main.py
```
